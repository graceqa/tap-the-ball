# Tap the Ball

This skill generates a simple and responsive web-based game called "Tap the Ball".

## Core Functionality

- **Game Generation**: Creates a complete, playable "Tap the Ball" game with HTML, CSS, and JavaScript files.
- **Responsive Design**: The game is designed to work on different screen sizes.

## How to Use

1.  Run the skill.
2.  The skill will generate the following files in the `assets` directory:
    -   `index.html`: The main game file.
    -   `style.css`: The stylesheet for the game.
    -   `script.js`: The JavaScript code for the game logic.
3.  Open the `index.html` file in a web browser to play the game.
